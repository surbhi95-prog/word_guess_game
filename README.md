# word_guess_game
A simple word guessing game built in Python. The player has a limited number of attempts to guess letters of a randomly chosen word. The game tracks score based on correct guesses and ends with either a win or loss message.

# features
1. Random word selection from a word bank
2. Underscore placeholders for hidden letters
3. Limited attempts for guessing
4. Scoring system (points per correct letter, penalties for wrong guesses)
5. Win/Lose conditions


# how to play
Run the Python script.
A random word is chosen and displayed as underscores.
Guess letters one by one.
Correct guesses reveal letters and add points.
Wrong guesses reduce attempts and deduct points.
The game ends when the word is fully guessed or attempts run out.
